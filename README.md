# COVID-19 India State-wise Analysis Dashboard

## 📊 Project Overview

This project presents a state-wise analysis of COVID-19 cases in India using an interactive dashboard.

The dashboard is designed to analyze COVID-19 data across different Indian states and provide an easy-to-understand visual representation of the available data.

## 🎯 Objectives

- Analyze COVID-19 data across Indian states.
- Compare COVID-19 cases between states.
- Identify state-wise patterns and trends.
- Present important information using charts and visualizations.
- Create an interactive and easy-to-understand dashboard.

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Microsoft Excel
- PowerPoint
- Data Visualization
- Data Analysis
